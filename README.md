# Avaya-CTI-Source-Code
## Overview

This repository contains the source code of our Avaya CTI (Computer Telephony Integration) product. The product provides standard telephony bar functions and supports integration with agent business systems, enabling efficient management of call center operations. 

Important Note: The source code in this repository is available for use, but the training code requires payment from users. For details on training code pricing and access, please contact our team.

### Telephony Bar Functions

The CTI product provides standard telephony bar functions, including the following:

- Login

- Logout

- Idle (Show Available)

- Busy (Show Unavailable)

- Answer

- Hold

- Hang Up

- Transfer

- Conference
